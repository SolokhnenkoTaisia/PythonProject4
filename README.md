# Product and Category

Учебный проект на Python для работы с товарами и категориями с использованием объектно-ориентированного программирования (ООП).

## Функциональность

- Класс `Product` хранит название, описание, цену и количество товара.
- Класс `Category` хранит название, описание и список товаров.
- Подсчёт общего количества созданных категорий.
- Подсчёт общего количества товаров во всех категориях.


### Наследование классов

Добавлены классы `Smartphone` и `LawnGrass`, которые наследуются от класса `Product`.

- `Smartphone` содержит дополнительные характеристики: эффективность, модель, объем памяти и цвет.
- `LawnGrass` содержит страну-производителя, срок прорастания и цвет.
- Сложение товаров разрешено только для объектов одного класса.
- В категорию можно добавлять только товары, созданные на основе класса `Product`, включая его дочерние классы.
- Добавлены тесты для проверки наследования, сложения товаров и работы категорий.

## Установка зависимостей

```bash
poetry install
```

## Запуск программы

```bash
poetry run python main.py
```

## Запуск тестов

```bash
poetry run pytest -v
```

## Проверка покрытия тестами

```bash
poetry run pytest --cov=src --cov-report=term-missing --cov-report=html
```

Последняя команда выводит процент покрытия кода и создаёт HTML-отчёт в папке `htmlcov`.
