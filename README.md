# Product and Category

Проект для работы с товарами и категориями с использованием ООП в Python.

## Функциональность

- Класс Product для хранения информации о товаре.
- Класс Category для хранения информации о категории и её товарах.
- Подсчёт общего количества категорий и товаров.

## Технологии

- Python 3.12
- Poetry
- Pytest
